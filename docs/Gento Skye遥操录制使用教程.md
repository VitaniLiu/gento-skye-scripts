# Gento Skye遥操录制使用教程

更新日期：2026-11-04。以下命令均在主机 av-pipeline 上执行。

## 一、遥操

### 启动脚本

打开一个终端，执行：

```bash
cd /home/descfly/gento-skye_scripts
scripts/teleop/teleop.sh
```

等待显示“底盘：已就绪”。先松开手柄 LB，让十字方向键回中，再按住 LB 操作。脚本持续运行，直到退出，无需填写运行时长。

### GameSir 手柄按键

LB 即左肩键，也称 L1。方向均以机器人自身朝向为准。

| 按键 | 功能 |
| --- | --- |
| 按住 LB + 十字键 ↑ | 前进 |
| 按住 LB + 十字键 ↓ | 后退 |
| 按住 LB + 十字键 ← | 向左转向，不是向左平移 |
| 按住 LB + 十字键 → | 向右转向，不是向右平移 |
| 松开 LB，或松开方向键 | 停止手动移动 |
| A | 停稳后自动返回本轮起点，具体见下文 |
| Y | 发送急停请求；必须查看机器人是否实际停止，不能当作全身已断电或夹爪已停止的确认 |

一次只按一个方向，不支持斜向组合。摇杆及其他按键不用于本脚本的底盘行驶控制。

### A 键返回

- **只遥操、不采集时**：松开 LB 和方向键，等底盘停稳，再按一下 A，返回本轮遥操起点。返回成功后程序继续待命，可开始下一轮。
- **配合采集时**：A 返回本段采集开始时的底盘位置。先结束采集，等待收尾完成，保持底盘停稳且 LB、方向键松开，再按 A。采集中不能执行返回。
- 返回期间不要操作 LB 或方向键；再次按 A，或操作 LB、方向键，会取消返回。
- 结束采集后若要使用 A 返回，不要先手动移动底盘。若提示返回被拒绝，按终端提示处理。

如果本次不需要 A 键返回，可改用：

```bash
scripts/teleop/teleop.sh --no-reset-button
```

### 结束遥操

松开 LB 和方向键，在遥操终端按 **Ctrl+C**，等待“底盘：已停止（停车确认成功）”。未确认停止时，现场检查机器人，必要时使用物理急停。

上述脚本控制底盘；Pico 上身和夹爪遥操需事先在现场连接并就绪。退出底盘脚本不会退出头显遥操。

## 二、采集

### 脚本功能

采集脚本按任务保存多段示范。每段示范称为一个 episode。脚本会检查采集条件、显示开始倒计时、录制机器人数据，结束后让操作者选择保存或丢弃；同一任务可连续采集，不用反复启动脚本。

采集期间保持遥操终端运行。只运行一份底盘遥操脚本，采集程序会自动关联它。头显遥操、机器人和相机应已就绪；采集脚本不会替你启动它们。

### 启动脚本

另开一个终端，执行：

```bash
cd /home/descfly/gento-skye_scripts
scripts/recording/record.sh
```

按提示输入任务文件夹名称，例如 `桌面拿杯`，按回车。已有同名任务会继续追加，新任务会自动创建；任务名不要包含路径分隔符。

### 采集按键

以下都是**采集终端的键盘按键**，不是手柄按键。进入任务后无需回车。

| 键盘按键 | 功能 |
| --- | --- |
| s（等待时） | 检查条件并开始一段采集 |
| s（预检或采集中） | 请求结束本段，等待文件收尾和检查 |
| y（收尾完成后） | 保存本段，分配正式 episode 编号 |
| n（收尾完成或异常待处理时） | 丢弃本段，移入丢弃区，不占正式编号 |
| Ctrl+C | 退出；未确认保存的数据留待处理，不会自动保存 |

**键盘 y 是保存；手柄 Y 是急停请求。采集结束后必须按键盘 y 才会保存。**

### 完整采集一段

1. 准备好物品和机器人起始姿态，底盘停稳，松开 LB 和方向键。
2. 在采集终端按 **s**。
3. 等预检和倒计时结束，显示 **“录制已开始”** 后再开始做任务。
4. 通过头显操作上身和夹爪，需要移动时使用 GameSir 手柄。
5. 任务完成后松开底盘按键，停稳，再在采集终端按 **s**。
6. 等待提示 **“本段收尾完成，尚未分配正式编号”**。
7. 按 **y** 保存，或按 **n** 丢弃。保存成功会显示完整目录和 `episodeXXXXXXXX` 名称。
8. 如需底盘返回本段起点，保持底盘未被手动移动，按手柄 **A**，等待返回完成。重新布置任务后，再按键盘 **s** 采集下一段。

每段最长 3600 秒，达到上限自动结束，收尾后仍需选择 y 保存或 n 丢弃。若提示异常或不能保存，该段留待处理；可按 n 丢弃，或 Ctrl+C 退出后检查。未处理当前段前不能开始下一段。

### 数据保存与结束

正式数据保存在机器人：

```text
/home/user/gento-skye_raw_data/<任务名>/episode00000000/
/home/user/gento-skye_raw_data/<任务名>/episode00000001/
```

同一任务自动递增编号，不覆盖已有段。未确认的数据位于 `_pending`，丢弃的数据位于 `_discarded`；丢弃不等于物理删除。

全部采集完成后，先保存或丢弃最后一段，在采集终端按 Ctrl+C，再退出遥操终端。不要在采集中先关闭遥操脚本。

需要查看未处理数据时，在主机项目目录执行：

```bash
scripts/recording/main.sh --list-pending
scripts/recording/main.sh --inspect RECORDING_ID
```

将 `RECORDING_ID` 替换为列表中的实际编号。
