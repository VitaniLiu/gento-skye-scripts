# 当前操作说明

## 遥操

启动：`./teleop.sh`。
L1 + 上/下：前进/后退，指令速度 0.2 m/s。
L1 + 左/右：旋转，指令角速度 0.2 rad/s。
松开控制：发零速，实际余动继续记录，稳定约 0.5 秒后完成该条路线。
Ctrl+C：关闭整个会话并等待停车确认。
A：在停稳且松开 L1/方向键时启动原路返回；再次按 A 或干预方向会取消。

复位成功且确认停车后继续待命，新路径以返回后的静止位置为记录基准。
输入或反馈异常会停车并可能结束会话，需要重新启动，不自动恢复运动。
遥操不再有默认 600/1800 秒总时长限制；单次自动返回仍有 120 秒限制。
不需要为无限时使用写很大的 --seconds 值。

## 已确认但尚未修改的遥操行为

十字键横纵轴同时非零时，controller.py 输出 diagonal_blocked 零速。
2026-11-02 14:30 和 14:32 的旋转中途停顿有相应输入记录。
用户要求先诊断，故此规则保持不变，不属于本次整理/无时限修改内容。

## 记录分类

会话日志保留全部输入/输出及事件，路线日志只收集遥操及其停车余动。
A 返回另外记录在会话里，避免与遥操去程混在一起。
每条路线均写开始和结束事件、终点位姿及是否确认静止。
未正常停稳或被中断的路线不能当成完整精度样本。

## Replay 注意

默认 replay.py 是离线预览，只有 --execute 才自动运动；不要求持续按 L1。
当前选定路线不会自动随最新文件变化。先绑定正确来源，确认当前位置，
准备制动按钮，再由操作者执行。回放结束会停车并退出它自己的回放会话。
历史数据缺什么就如实标明，不能用速度积分冒充逐点实测里程计。
