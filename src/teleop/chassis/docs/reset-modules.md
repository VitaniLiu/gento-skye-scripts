# 复位运行模块

本目录只放运行模块和所需配置。测试已集中到 ../tests，部署与验证工具在 ../tools。

- button.py：A 键进入/取消复位，成功后重新建立待命状态。
- hybrid.py：当前实际使用的混合复位；记录动作分段、余动和实测路径，倒序返回。
- retrace.py：轨迹采样校验及 Pose 结构；保留兼容控制器供回归测试使用，A 键实际选择 hybrid。
- logic.py：坐标、误差、反馈新鲜度及独立旧入口控制基础。
- reset.py：机器人侧 ROS 连接、实际位姿读取、停车确认、独立预览入口。
- config/verification.json：独立旧入口所需的历史人工验证配置；并非当前 A 键入口的新增验收锁。

常用入口在项目根目录 sender.py，而不是直接运行本目录文件。
A 返回限制仍为每次 120 秒，路径距该轮记录起点 1 米内；
这是单次自动返回边界，不是遥操会话的总时长限制。
复位成功后继续待命；严重异常仍结束会话并执行停车流程。
